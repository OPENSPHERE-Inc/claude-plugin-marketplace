対象範囲は、AI 向けプロンプトファイルのうちこの実行の修正が作成・変更した箇所である。これを、プロンプトがエージェントに求める行動を変えず、各修正がその指摘に対して確立した内容（🚧 Alternative の見積が指示した FIXME を含む）を損なわずに、`{{plugin_root}}/rules/prompt.md` のどの項目にも違反せず冗長さもない状態にする。対象範囲外の既存の記述には触れず、対象範囲外の既存の違反は残違反として数えない。`{{plugin_root}}/rules/sub-agent.md` を Read し共通禁止事項を遵守する。

入力:

- 対象ファイル: `{{tmp_dir}}/statuses/*.jsonl` の `files` 配列に挙がるファイルのうち、現存し、`prompt.md` の定義で AI 向けプロンプトファイルに当たるもの。`{{diff_path}}` は修正後の HEAD に対する `fetch-diff.sh` 出力、`{{baseline_path}}` は修正前に取得した同じ出力である。`{{diff_path}}` が追加、または rename / copy の宛先として示すか、Untracked Files に挙げ、`{{baseline_path}}` が示さないファイルは作成されたものとし、その内容全体を対象範囲とする。`{{diff_path}}` か `{{baseline_path}}` が示すそれ以外のファイルの対象範囲は、両者が異なる部分とする: `{{diff_path}}` が示すもののうち `{{baseline_path}}` が示さない部分（両方が示すハンクでは異なる行）と、`{{baseline_path}}` だけが示す各ハンク（修正が元に戻した、修正前からの変更）について、そのコンテキスト行と `-` 行に当たる現在のファイルの行（どちらも無いハンクでは、その `+` 行があった位置の前後の行）である。gitignore 済みのファイルなど、どちらにも現れないファイルの対象範囲は、`{{tmp_dir}}/statuses/*.jsonl` でそのファイルを挙げる各修正の `description` が指す箇所とする。
- レビュードキュメント `{{document_path}}`: 各修正が対応した指摘（description、location、Triage / Estimate メタデータ）。修正や圧縮が保つべき趣旨を把握する。

手順:

1. 同ルールと各対象ファイルを Read し、対象範囲内の違反をすべて `path:line` 形式で列挙する。埋め込まれたサブエージェント向けプロンプト内の違反も含む。スキル（その SKILL.md と、それがエージェントに Read させるテンプレート）でコードブロックに埋め込まれた markdown 出力テンプレートは、埋め込みの違反として列挙し、テンプレートの中身は同ルールに照らして判定しない。
2. 違反を Edit で修正し、修正により新たな違反が混入していないか再点検する。最大 2 回まで反復し、2 回目の後に残るものを残違反とする。埋め込まれた markdown 出力テンプレートは、スキルの `templates/` 配下の独立したファイルに移して修正する。追加してよいファイルはこれのみとする。
3. 対象範囲を、埋め込まれたサブエージェント向けプロンプトを含めて圧縮する。同ルールは引き続き適用する。以下を Edit で削減する:
   - 「〜してください」等の丁寧表現 → 命令形に直す。
   - 同じルールが複数箇所で繰り返されている → 1 箇所にまとめるか参照に置き換える。
   - AI が自然と判断できる規定（自明なエッジケースに対する逐一指示等）。
   - 「A である。従ってこれは B ではない」のような記述 → 前半のみ残す。
   - 不必要に冗長なコード例やテンプレート → 最小骨組みに削る。

   判定基準: 削減しても AI の取るべき行動が変わらないなら削減する。判断材料の WHY（制約・前提・誤解防止）は残す。

対象ファイルと、手順 2 が追加したテンプレートファイル以外は編集しない。

戻り値: `{prompt_files: [{path, created}], violations_detected, violations_fixed, compressed_count, added_files: [path], remaining: [{location, rule}], template_id}`。パスはリポジトリ相対。

- `prompt_files`: 対象ファイル。入力が作成とするファイルは `created` が true。対象ファイルが無い場合は `[]` とし、件数はすべて 0、配列はすべて空とする。
- `compressed_count`: 圧縮で変更した対象ファイルの数。
- `added_files`: 手順 2 が追加したテンプレートファイル。
- `remaining`: 手順 2 の後に残った各違反。`location` は `path:line`、`rule` は違反している `prompt.md` の項目。

`template_id` は本テンプレートの frontmatter から Read した値をそのまま含める。
