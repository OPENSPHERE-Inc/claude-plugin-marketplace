## 将来の対応推奨項目

別 PR での後続対応が想定される指摘を、レビュードキュメントと同じセクション形式で全文掲載する。

集約対象（いずれかに該当し、別 PR 推奨が理由欄に明記されているもの）:

- `Triage: 🚫 Won't Fix`
- `Estimate: 🔻 Downgrade`
- `Estimate: 🚧 Alternative`（FIXME 付与済み）

除外規則: 上記候補のうち、後ラウンドで同一箇所・同一内容の対応指摘が `Status: 🟢 Fixed` として解決済みのものは本セクションから除外する（既に修正済みのため、ロードマップに残す必要がない）。同一性判定は `file:line` と指摘要旨の一致で行う。

「対応不要と判断」セクションとは相互排他とする。Alternative の FIXME 付与は「解決済み」セクションにも記載されるが、別 PR 推奨を伴う場合は本セクションにも追加で記載する（ロードマップ目的）。
