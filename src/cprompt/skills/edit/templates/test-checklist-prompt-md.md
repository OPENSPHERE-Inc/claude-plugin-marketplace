# prompt.md テストチェックリスト

プロンプト規律のルールファイル（`prompt.md` ルール）を編集対象とする場合に、/cprompt:edit ステップ 5 のテストサブエージェントへ渡すチェックリスト雛形。

## チェック項目

1. 「避けるべきメタ説明パターン」リストの各項目について、それぞれを他項目と区別する基準は何か?
2. 各項目が重複していないことが、本文（例示と括弧書き）から読み取れるか?
3. 1 文中に複数の避けるべきパターンが含まれる場合、文全体を削除すべきか、該当部分のみ削除すべきか? その方針は本文に明示されているか?
4. 各項目の判定基準は、項目固有のものか、それともリスト全体に共通の判定基準に従うのか? その関係は本文に明示されているか?
5. 「他ステップへの先読み」と「説明的前置き」を区別する具体例を 1 つ示せ。
6. 「他ステップへの先読み」と「編集者向けの保守ガイドライン」が独立項目として並存する根拠を述べよ。
7. メタ説明的な記述がリスト内のいずれの例にも厳密には該当しない場合、どう扱うべきか?
