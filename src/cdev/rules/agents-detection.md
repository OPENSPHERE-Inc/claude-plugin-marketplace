# エージェント検出・割り当て共通ルール

cdev の teammate が、あるタスク（例: ビルド / テストエラーを修正すべき専門家）に対応する専門エージェントを 1 つ解決する共通手順。呼び出し元のテンプレートは「マッチ対象」と「結果の記録先」のみを指定する。

## 列挙

以下の優先順位でエージェントの `**/*.md` を列挙し、各ファイルの frontmatter の `name` / `description` を Read する。同一 `name` が複数スコープに存在する場合は上位スコープのものを採用し、存在しないスコープはスキップする。`{{plugin_root}}` は本ルールを Read させた起動プロンプトの起動変数値（呼び出しテンプレートと同一）。

1. プロジェクトスコープ: `.claude/agents/**/*.md`（作業ディレクトリ基準）
2. ユーザースコープ: `~/.claude/agents/**/*.md`
3. プラグイン同梱: `{{plugin_root}}/agents/**/*.md`

## 選定

各エージェントの `description` が記述する専門性を、呼び出し元が指定したマッチ対象（エラー内容・言語・ビルドシステム・サブシステム・テストフレームワーク等）と照合し、最も適合するエージェントを 1 つ選ぶ。いずれのスコープにも妥当に適合するエージェントがない場合は `general-purpose` とする。

## 結果

選定したエージェントの `name`（別の Agent 呼び出しが `subagent_type` に渡す値）を、呼び出し元が指定した記録先フィールドに格納する。プラグイン同梱（スコープ 3）のエージェントを採用する場合は、名前空間を前置した値（例 `cdev:comment-sensei`）を格納する。
